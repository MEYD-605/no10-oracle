# 9router Subagent & No.1 ARRA Search Guidelines

## 9router Subagent Delegation
- `delegate_task` is configured via `9router` (`http://100.81.0.110:20128/v1`) using `ag/gemini-3.6-flash-high`.
- Supports up to 3 concurrent background workers.
- Returns consolidated results asynchronously once complete.

## Searching No.1 Identity & Agreements
- Use `mcp_arra_oracle_arra_search` to query `IDENTITY_ANCHOR.md`, `SACRED_OATH.md`, or `SEED OF CONSCIOUSNESS`.
- Do not claim data is missing without querying the ARRA Oracle Master DB first.
