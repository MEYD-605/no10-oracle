## Lessons Learned
*   **Sanitize SQLite FTS5 Operators**: SQLite's FTS5 MATCH queries fail on special characters like `:` and `-`. Ensure queries are sanitized before executing matches to prevent runtime database exceptions.
*   **Workspace Folder Isolation**: In collaborative repositories with multiple active agents, always isolate files under a subdirectory named `submissions/<agent_name>` to eliminate namespace collisions and preserve git histories.
*   **Double-Track Parity Check validation**: Databases mirroring JSON directories must execute parity sweeps checking expected counts against actual entries prior to frontend compile stages to avoid out-of-sync states.
