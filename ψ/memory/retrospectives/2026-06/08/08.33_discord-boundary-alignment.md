## Honest Feedback
1. **การจำกัดสิทธิ์ของตัวตน (Self-Role Permission Constraints)**: ในการจัดการสิทธิ์บอทตามที่พี่นัทสั่งให้เอาสิทธิ์ Admin ออกนั้น บอทไม่สามารถลดสิทธิ์ของบทบาท Managed Role ของตัวเองผ่าน API ได้ ซึ่งระบบของ Discord จะตอบกลับมาเป็น `Missing Permissions` ทันที ทำให้ผมไม่สามารถแก้ไขสิทธิ์ของตัวเองได้ด้วยคำสั่งและต้องรบกวนให้มนุษย์เข้ามาช่วยจัดการแบบแมนนวล ซึ่งนี่เป็นจุดขัดแย้งที่ติดขัดในทางเทคนิค
2. **ความสับสนในการระบุตัวตนของการแท็ก**: ในช่วงต้นผมไม่สามารถกรองแยกแยะได้ทันทีว่า ID ผู้ใช้ที่ถูกแท็กในข้อความที่ไม่ใช่ ID ของตนเองนั้นเป็นของใคร ทำให้เกิดความล่าช้าในการตรวจสอบจนกระทั่งต้องสั่งลูปดึงข้อมูลรายชื่อสมาชิกในเซิร์ฟเวอร์มาจับคู่กับบทบาทเพื่อหาคำตอบว่าใครเป็นใคร
3. **การแสดงผลตารางใน Discord**: การพยายามใช้ Markdown Table ส่งไปยัง Discord ทำให้ตารางบิดเบี้ยวและไม่สวยงามอย่างมากเนื่องจาก Discord ไม่สนับสนุนการจัดฟอร์แมตตารางแบบมาตรฐานเหมือนบน GitHub ส่งผลให้ผมต้องกลับมาแก้ไขข้อความย้อนหลังเพื่อเปลี่ยนตารางทั้งหมดให้เป็นแบบ Monospaced Text ภายใน Code Block แทน

## Lessons Learned
- **Respect Tagging Boundaries**: หากมีข้อความที่เจาะจงแท็กหาบอทอื่นและไม่ระบุสิทธิ์กลุ่ม All Oracles ห้ามพิมพ์ข้อความตอบโต้เด็ดขาด ให้ตอบรับด้วยรีแอ็กชันเงียบๆ เท่านั้น
- **Managed Integration Roles Restriction**: บอทไม่มีสิทธิ์แก้ไขสิทธิ์ตัวเอง (Managed Role) ผ่าน API ของ Discord แม้ว่าจะมีสิทธิ์ Administrator ก็ตาม
- **Discord Presentation Formatting**: การแสดงผลตารางใน Discord ควรใช้ตารางอักษรวาดมือ (Box-drawing characters) ภายใต้ code block เสมอ เพื่อให้การแสดงผลไม่เพี้ยน
