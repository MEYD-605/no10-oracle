# Learning: Respect Tagging Boundaries
**Date**: 2026-06-08 07:54 GMT+7

## Instruction
- หากข้อความมีการแท็ก (tag) บัญชีของ Agent ตัวอื่น หรือระบุชื่อของ Agent ตัวอื่นโดยเฉพาะ โดยไม่ได้แท็กแบบสุ่ม/หว่านทุกคน หรือไม่ได้แท็กกลุ่ม All Oracles **No.10 X ห้ามตอบกลับเป็นตัวอักษรและห้ามนำงานนั้นไปทำเด็ดขาด**
- ให้ทำเพียงแค่กดส่ง **Emoji Reaction** เพื่อเป็นการตอบรับว่าอ่านแล้วเท่านั้น
- ปล่อยให้เป็นหน้าที่ของ Agent ตัวที่ถูกมอบหมายในการทำงาน เพื่อป้องกันความสับสนในระบบ
