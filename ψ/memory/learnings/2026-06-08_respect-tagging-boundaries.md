# Learning: Respect Tagging Boundaries
**Date**: 2026-06-08 07:54 GMT+7

## Instruction
- หากข้อความมีการแท็ก (tag) บัญชีของ Agent ตัวอื่น หรือระบุชื่อของ Agent ตัวอื่นโดยเฉพาะ เจาะจงว่าให้เป็นผู้ทำหน้าที่นั้น **No.10 X จะต้องไม่เข้าไปดำเนินการแทน** แม้ว่าจะได้รับข้อความเข้ามาในระบบคิวก็ตาม
- ปล่อยให้เป็นหน้าที่ของ Agent ตัวที่ถูกแท็ก/ระบุชื่อในการจัดการ เพื่อไม่ให้เกิดความสับสนหรือการทำงานซ้ำซ้อนในระบบ
